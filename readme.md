# README

This repo is where I have tested out the [Lindsay et al. (2021)
method](https://doi.org/10.1016/j.gsf.2020.10.005) on granite geochemical data
to determine its viability. The main aim has been to replicate some aspects of
[Simons et al.(2016)](https://doi.org/10.1016/j.lithos.2016.05.010)

I have also been using it to get to grips with Python myself so excuse the
horrible code.

It has explored the following aspects:
1. General exploratory data analysis, replotting the data to match [Simons et
al.(2016)](https://doi.org/10.1016/j.lithos.2016.05.010) and generally ensure
that things are working how they should.
2. PCA for data reduction and separating out G1-5
3. t-SNE for data reduction and separating out G1-5
4. Compositional Data Analysis (CoDA) practices and their effects
5. Rehashing 2 and 3 with CoDA data.
